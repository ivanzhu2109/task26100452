# task26100452

商机阶段转化分析库（Go）。阶段历史与分析快照均保存在进程内存中，由上层直接调用。

## 能力

- `NewSnapshot(records []Record) *Snapshot`：从完整历史创建只读快照，输入可整体乱序，构建后不再修改。
- `(*Snapshot).ConversionMetrics(startMs, endMs int64) []ConversionMetric`：查询左闭右开窗口 `[startMs, endMs)` 内五组转化（初探→发现、发现→演示、演示→提案、提案→谈判、谈判→赢单）的分母、分子与转化率。

## 规则要点

- 分母：窗口内至少进入过一次来源阶段的不同商机数；分子：窗口内存在合格记录对（先进入来源、严格晚于它进入目标、两条都在窗口内、两条之间无赢单/输单）的不同商机数。
- 赢单/输单结束一轮销售过程，关闭前的来源记录不能与关闭后的目标记录配对。
- 跳阶段不补记被跳过的阶段；同一商机每组分母、分子最多各贡献 1；分母为 0 时转化率为 0。
