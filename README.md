# task26100452

商机阶段转化分析库（Go）。阶段历史与分析快照均保存在进程内存中，
由上层直接调用；快照构建后只读，不再修改。

## 能力

- `funnel.NewSnapshot(records)`：从完整历史创建只读快照（输入可乱序）。
- `snapshot.Query(startMs, endMs)`：按左闭右开时间窗口查询五组转化
  （初探→发现、发现→演示、演示→提案、提案→谈判、谈判→赢单）的
  分母、分子与转化率。

## 统计口径

- 分母：窗口内至少进入过一次来源阶段的不同商机数。
- 分子：窗口内存在一对合格记录（先来源、后目标、中间无赢单/输单）
  的不同商机数；同一商机每组最多贡献 1。
- 赢单/输单结束一轮销售过程，关闭前后的记录不能跨轮配对。
- 跳阶段不补记被跳过的阶段；转化率为分子/分母，分母为 0 时返回 0。
